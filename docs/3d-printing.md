# Enclosure and 3D printing

The enclosure is an open-top square box with a separate flat lid (holes for wires), printed at the Sanjivani University Makerspace.

| Setting | Value |
|---|---|
| Printer | Bambu Lab A1 mini (sent over LAN from Bambu Studio) |
| Nozzle | 0.4 mm, standard flow |
| Plate | Textured PEI |
| Filament | PLA Basic, white |
| Process | 0.28 mm Extra Draft @BBL A1M |
| Bed adhesion | Outer brim, 5 mm |
| Prime tower | Enabled |
| Auto bed levelling / flow calibration | On / On |
| Timelapse | Off |
| Filament used | 32.56 m, 98.66 g |
| Time | 1 h 27 m printing, 1 h 38 m total |

Values are read from the Bambu Studio slicing-result screenshot (`media/photos/bambu-studio-send-print-job.jpg`).
