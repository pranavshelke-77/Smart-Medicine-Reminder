MedAlarm — Smart Medicine Reminder & Emergency Alert System

A small, screen-free device that reminds a patient to take their medicine on time. There is no LCD or keypad on the box: the ESP32 creates its own Wi-Fi network, and the medicine name, reminder time and alarm are set from any phone browser. A buzzer sounds when the dose is due, a physical button stops it, and a separate emergency button raises an alert.

The enclosure was designed for this build and 3D-printed in PLA on a Bambu Lab A1 mini. Wiring and soldering are in progress; no test results are claimed yet.

SEC 02

The problem, and our idea

Missed or late doses are common, especially for elderly people who take several medicines a day. Phone alarms are easy to dismiss and forget, and a dedicated reminder is easier to notice when it sits next to the medicine.

Our first concept used a display on the device to set reminders. We removed the screen to make the device smaller, simpler and cheaper: the user's phone already has a good screen and keyboard. The ESP32 serves a small web page over its own Wi-Fi network, so no app, router or internet connection is needed.

The question we are answering

Can a screen-free ESP32 device, configured entirely from a phone browser, reliably sound a medicine reminder at the set time and let the user stop it, or raise an emergency alert, with one button press?

SEC 03

How it works

The ESP32 starts a Wi-Fi access point called MedicineAlarm. The phone joins it and opens http://192.168.4.1. From that page the user sets the clock (from the phone's own time), the medicine name and the daily reminder time. Every loop the ESP32 compares its clock with the reminder; when they match it pulses the buzzer until the stop button, or Stop buzzer on the phone, is pressed. The emergency button sets an alert flag that is visible on the phone's status page.

A reminder aid, not a medical device

MedAlarm helps people remember a dose; it does not dispense or verify medicine. Dosing must follow a healthcare professional's instructions, and the prototype should never be the only reminder.

Buttons are active-low: the firmware enables the ESP32's internal pull-up resistors, so a press reads LOW. An ESP32 GPIO should not source more than about 20 mA continuously; check the buzzer's rating and use an NPN transistor driver if it draws more.

/*
  MedAlarm - Smart Medicine Reminder and Emergency Alert System
  Board : ESP32 DevKit V1 (Arduino IDE, "ESP32 Dev Module")
  Mode  : ESP32 runs its own Wi-Fi access point; the phone connects to it
          and opens http://192.168.4.1 to set the reminder. No LCD/OLED.

  Wiring (see docs/wiring.md)
    Active buzzer  +  -> GPIO 25     -  -> GND
    Stop button       -> GPIO 26 and GND (internal pull-up)
    Emergency button  -> GPIO 27 and GND (internal pull-up)

  Changes from the first draft:
    - /save validates the time BEFORE changing the stored reminder.
    - /clear resets the emergency flag (previously it could never be cleared).
*/

#include <WiFi.h>
#include <WebServer.h>
#include <time.h>

const char* apName = "MedicineAlarm";
const char* apPassword = "MedAlarm123";   // change before demonstrating

WebServer server(80);

const int BUZZER_PIN = 25;
const int STOP_PIN = 26;
const int EMERGENCY_PIN = 27;

String medicine = "Medicine";
int alarmHour = 9;
int alarmMinute = 0;

bool alarmActive = false;
bool emergencyAlert = false;
int lastTriggeredDay = -1;

bool clockIsSet() {
  time_t now = time(nullptr);
  return now > 1700000000;
}

void stopAlarm() {
  alarmActive = false;
  digitalWrite(BUZZER_PIN, LOW);
}

void redirectHome() {
  server.sendHeader("Location", "/");
  server.send(303);
}

void handleRoot() {
  server.send(200, "text/html", page);
}

void handleSave() {
  if (!server.hasArg("med") || !server.hasArg("time")) {
    server.send(400, "text/plain", "Invalid reminder settings");
    return;
  }

  String t = server.arg("time");
  int colon = t.indexOf(':');
  if (colon <= 0) {
    server.send(400, "text/plain", "Invalid reminder settings");
    return;
  }

  int newHour = t.substring(0, colon).toInt();
  int newMinute = t.substring(colon + 1).toInt();
  if (newHour < 0 || newHour > 23 || newMinute < 0 || newMinute > 59) {
    server.send(400, "text/plain", "Invalid reminder settings");
    return;
  }

  medicine = server.arg("med");
  alarmHour = newHour;
  alarmMinute = newMinute;
  lastTriggeredDay = -1;
  redirectHome();
}

void handleSetTime() {
  if (!server.hasArg("time")) {
    server.send(400, "text/plain", "Missing time");
    return;
  }

  String t = server.arg("time");
  int y, mo, d, h, mi;

  if (sscanf(t.c_str(), "%d-%d-%dT%d:%d", &y, &mo, &d, &h, &mi) != 5 ||
      y < 2024 || mo < 1 || mo > 12 || d < 1 || d > 31 ||
      h < 0 || h > 23 || mi < 0 || mi > 59) {
    server.send(400, "text/plain", "Invalid date and time");
    return;
  }

  struct tm tmNow = {};
  tmNow.tm_year = y - 1900;
  tmNow.tm_mon = mo - 1;
  tmNow.tm_mday = d;
  tmNow.tm_hour = h;
  tmNow.tm_min = mi;
  tmNow.tm_isdst = -1;

  time_t epoch = mktime(&tmNow);
  struct timeval tv = { epoch, 0 };
  settimeofday(&tv, nullptr);
  redirectHome();
}

void handleStatus() {
  String s = "Medicine: " + medicine +
    "\nReminder: " + String(alarmHour) + ":" +
    (alarmMinute < 10 ? "0" : "") + String(alarmMinute) +
    "\nClock set: " + String(clockIsSet() ? "Yes" : "No") +
    "\nAlarm active: " + String(alarmActive ? "Yes" : "No") +
    "\nEmergency alert: " + String(emergencyAlert ? "YES" : "No");
  server.send(200, "text/plain", s);
}

void handleStop() {
  stopAlarm();
  redirectHome();
}

void handleEmergency() {
  emergencyAlert = true;
  server.send(200, "text/plain",
    "Emergency alert registered on the device. "
    "No SMS or telephone call was sent.");
}

void handleClear() {
  emergencyAlert = false;
  redirectHome();
}

void setup() {
  Serial.begin(115200);

  pinMode(BUZZER_PIN, OUTPUT);
  digitalWrite(BUZZER_PIN, LOW);
  pinMode(STOP_PIN, INPUT_PULLUP);
  pinMode(EMERGENCY_PIN, INPUT_PULLUP);

  WiFi.mode(WIFI_AP);
  WiFi.softAP(apName, apPassword);

  server.on("/", handleRoot);
  server.on("/save", handleSave);
  server.on("/settime", handleSetTime);
  server.on("/status", handleStatus);
  server.on("/stop", handleStop);
  server.on("/emergency", handleEmergency);
  server.on("/clear", handleClear);
  server.begin();

  Serial.print("Connect to Wi-Fi: ");
  Serial.println(apName);
  Serial.print("Open browser at http://");
  Serial.println(WiFi.softAPIP());
}

void loop() {
  server.handleClient();

  if (digitalRead(STOP_PIN) == LOW) {
    stopAlarm();
  }

  if (digitalRead(EMERGENCY_PIN) == LOW) {
    emergencyAlert = true;
  }

  if (clockIsSet()) {
    time_t now = time(nullptr);
    struct tm localTime;
    localtime_r(&now, &localTime);

    if (localTime.tm_hour == alarmHour &&
        localTime.tm_min == alarmMinute &&
        localTime.tm_yday != lastTriggeredDay) {
      alarmActive = true;
      lastTriggeredDay = localTime.tm_yday;
    }
  }

  if (alarmActive) {
    digitalWrite(BUZZER_PIN, (millis() / 400) % 2);   // beep 400 ms on / off
  } else {
    digitalWrite(BUZZER_PIN, LOW);
  }

  delay(10);
}

Known limitations of version 1

  • One daily reminder only; multiple medicines need a schedule list.
  • The clock is lost after a power cut and must be set again (DS3231 RTC upgrade planned).
  • The emergency alert is local: it shows on the status page but does not notify anyone else. GSM or an internet service is needed for that.
  • Change the default Wi-Fi password before demonstrating the device.

SEC 09

Operating it from a phone

  1. Power the device from USB.
  2. On the phone, open Wi-Fi settings and join MedicineAlarm (password MedAlarm123 by default).
  3. Open a browser and go to http://192.168.4.1.
  4. Set the current date and time, then save the medicine name and reminder time.
  5. At the reminder time the buzzer sounds. Press the physical stop button, or Stop buzzer on the phone.

SEC 10

          
Testing plan

        

        
No results yet. Measured results will be published here once the device is wired and the firmware is running. Record raw results in data/test-log-template.csv.

        

          
Reminder accuracy
Set a reminder 2 minutes ahead; record the actual buzzer start time against the phone clock. Repeat 10 times.

          
Clock drift
Set the clock, leave the device running 24 h, compare with the phone. Report seconds of drift per day.

          
Stop button
Press the physical button and the phone's Stop buzzer during an alarm; confirm it stops every time and does not retrigger the same day.

          
Emergency flag
Press the emergency button; confirm the status page shows the alert and that Clear emergency resets it.

          
Wi-Fi range
Distance at which the phone can still load the control page, indoors through one wall.

          
Buzzer loudness
Sound level at 1 m with a phone sound-meter app, and whether it is audible from the next room.

          
Power loss
Unplug and replug: confirm the status shows "Clock set: No" and the device recovers after setting the time.

          
Fit in enclosure
Board, buttons and buzzer fit without strain on wires; USB port reachable with the lid on.

        

      

    


    
    

      

        

          
SEC 11

          
Safety and limitations

        

        
    
          
  • This is a reminder aid, not a medical device. Never rely on it as the only reminder for critical medication.
    • 
          
  • Only low-voltage USB power is used. Do not connect any mains wiring to the device.
    • 
          
  • Use a ventilated area and a stand for the soldering iron; let joints cool before handling the PLA box (PLA softens around 60 °C).
    • 
          
  • Check the buzzer's current before connecting it directly to a GPIO pin; use a transistor driver if needed.
    • 
          
  • The emergency button does not call or message anyone in version 1. Do not present it as an emergency service.
    • 
          
  • Change the default Wi-Fi password so other people nearby cannot change the reminders.
